    ```python
    def perlin_worm_path(start, seed, length=200, step_size=1.0):
        """Follow 3D simplex noise gradient to carve natural cave skeleton."""
        rng = np.random.default_rng(seed)
        path = [np.array(start, dtype=np.float64)]
        for i in range(length):
            pos = path[-1]
            # Sample noise gradient (central differences on 3D simplex)
            eps = 0.5
            gx = (noise3d(pos[0]+eps, pos[1], pos[2]) - noise3d(pos[0]-eps, pos[1], pos[2])) / (2*eps)
            gy = (noise3d(pos[0], pos[1]+eps, pos[2]) - noise3d(pos[0], pos[1]-eps, pos[2])) / (2*eps)
            gz = (noise3d(pos[0], pos[1], pos[2]+eps) - noise3d(pos[0], pos[1], pos[2]-eps)) / (2*eps)
            grad = np.array([gx, gy, gz])
            grad_norm = np.linalg.norm(grad)
            if grad_norm > 1e-6:
                direction = grad / grad_norm
            else:
                direction = rng.standard_normal(3)
                direction /= np.linalg.norm(direction)
            # Add randomness for variety
            direction += rng.standard_normal(3) * 0.3
            direction /= np.linalg.norm(direction)
            path.append(pos + direction * step_size)
        return np.array(path)
    ```
    Use opensimplex or the project's existing noise implementation for `noise3d`.

    **Step 2 — Cellular automata chamber expansion:**
    Create 3D voxel grid. Mark path voxels as "air". Run 3-5 iterations of cellular automata: a voxel becomes air if >= 13 of 26 neighbors are air. This naturally expands passages into chambers at path nodes (where multiple paths converge or path curves back).

    **Step 3 — Variable radius:**
    Along path, modulate carving radius: `radius = base_radius * (1.0 + 0.5 * noise1d(path_distance * 0.1))`. Wider at low-gradient points (chambers), narrower at high-gradient (passages).

    **Step 4 — Marching cubes mesh generation:**
    Use `skimage.measure.marching_cubes` (or implement basic marching cubes if sklearn unavailable) on the 3D density field. Density < 0 = air (cave interior), > 0 = rock. This produces a closed manifold mesh with proper ceiling, wall, and floor geometry.

    **Step 5 — Surface separation:**
    After marching cubes, classify faces by normal direction: `normal.z > 0.7` = floor, `normal.z < -0.7` = ceiling, else = wall. Assign material indices accordingly.

    **Step 6 — Terrain connection:**
    Find cave path entry point nearest to terrain surface. Ensure entrance Z matches `BakedTerrain.sample_height(x, y)` within 1m tolerance. Mark terrain cells above cave entrance as holes (for Unity terrain hole punching).
