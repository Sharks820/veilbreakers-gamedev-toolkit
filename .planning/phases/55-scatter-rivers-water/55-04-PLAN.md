    **Socket server fixes (6.40-6.48):**

    **6.40 (F261):** In register(), before `bpy.app.timers.register()`, check for existing timer and unregister it. Use module-level `_active_timer` reference.

    **6.41 (F262):** In unregister(), iterate `_client_threads` list, call `thread.join(timeout=5.0)` on each. Set `_shutdown_event` so threads exit their loops.

    **6.42 (F263):** Replace single `result_event` with `Dict[str, threading.Event]` keyed by command UUID. Each command gets unique event. Background thread sets only its own event. Main thread waits on its specific event.

    **6.43 (F264):** Change `_process_commands` from `queue.get_nowait()` (1 per tick) to `while not queue.empty(): ...` with max batch of 50 per tick. Prevents 100 cmd/sec ceiling.

    **6.44 (F265):** In response wrapper, detect `{"status": "partial"}` and wrap it in standard response format with `success=True, result=original_result`.

    **6.45 (F266):** Before `sendall()`, check `len(json.dumps(result))`. If > MAX_RESPONSE_SIZE (10MB), return `{"error": "Response too large", "size": actual_size, "limit": MAX_RESPONSE_SIZE}`.

    **6.46 (F267):** Set `command_queue = Queue(maxsize=1000)`. On `queue.full()`, return `{"error": "Server overloaded, queue full"}` instead of blocking.

    **6.47 (F268):** Background `_handle_client` thread MUST NOT call any `bpy.*` API. It only parses JSON and puts command dict into queue. Main thread timer callback reads bpy.

    **6.48 (F269):** Register `bpy.app.handlers.load_post` callback that calls `bpy.app.timers.unregister(_process_tick)`. Re-register timer in load_post handler.

    **Settlement/handler bugs (6.28-6.39):**

    **6.28 (F249):** Add `@lru_cache(maxsize=4096)` to `_sample_heightmap` or use a spatial hash cache. 200 buildings * 4 corners = 800 lookups, most hitting nearby cells.

    **6.29 (F250):** Change `platform_elevation = max_elevation` to `platform_elevation = mean(corner_elevations)` for terraced terrain.

    **6.30 (F251):** Reorder: compute heightmap-aware data FIRST, then `_place_buildings()`.

    **6.31 (F252):** Pass `heightmap` parameter to `_generate_alleys()` and `_scatter_settlement_props()`. Use for Z-placement.

    **6.32 (F253):** Change raycast ceiling from 10000 to `float('inf')` or `max_terrain_height * 2`.

    **6.33 (F254):** Wrap each battlement in try/except. On failure, log warning and continue to next battlement, not skip all remaining.

    **6.34 (F255):** On GLB import failure, raise `ImportError(f"Failed to import {glb_path}: {e}")` instead of logging and continuing without the prop.

    **6.35 (F256):** On terrain alignment failure, raise `RuntimeError` instead of silently placing at last known Z.

    **6.36 (F257):** Remove `env_generate_world_terrain` from handler registry. Add deprecation comment pointing to new pipeline.

    **6.37 (F258):** Replace ~25 inline lambda handlers with named functions wrapped in `_safe_handler(fn)` decorator that adds try/except + logging.

    **6.38 (F259):** Remove duplicate `terrain_validate_tile_seams` registration. Keep only one pointing to canonical function.

    **6.39 (F260):** Change weapon type fallback from silent sword default to `raise ValueError(f"Unknown weapon type: {weapon_type}")`.
