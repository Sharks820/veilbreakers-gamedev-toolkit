    **terrain_seam_guard.py** (NEW):
    Create SeamGuard class:
    - `__init__(self, tile_width, tile_height, guard_width=0.1)` — guard_width as fraction of tile size (default 10%)
    - `FORBIDDEN_PASSES = {"pass_erosion", "pass_waterfalls", "pass_materials", "pass_materials_v2"}` — set of pass names blocked in guard band (F800)

    - `apply_hero_blend(self, base_height, hero_height, x, z) -> float` — `base + blend_weight(x,z) * (hero - base)`

    Create TerrainNodeRegistry class:
    - `_tiles: Dict[Tuple[int,int], Dict]` storing config + BakedTerrain ref per (tile_x, tile_y)
    - `register(tile_x, tile_y, config, baked)` — store; if already registered with different config (seed, resolution, height_scale), raise `ConfigConsistencyError` (F810)
    - `get_neighbor(tile_x, tile_y, direction: str) -> Optional[BakedTerrain]` — direction in {"north","south","east","west"}, returns neighbor's BakedTerrain or None
    - `get_shared_edge(tile_a, tile_b) -> Tuple[np.ndarray, np.ndarray]` — returns height arrays along shared boundary for both tiles
    - `cross_tile_boundary_validate(tile_a, tile_b) -> ValidationResult` — compare shared edge heights, fail if max diff > atol (F811)

    Wire SeamGuard into terrain_pipeline.py: before each pass in DAG execution, wrap the pass callable to check `is_forbidden` for each cell being mutated. Apply blend_weight when merging hero deltas into base terrain.

    In terrain_stratigraphy.py or terrain_features.py, implement `apply_fault_displacement(height_grid, fault_trace, fault_type, offset_m)`:
    - `fault_trace`: polyline [(x,z)...] defining fault position
    - `fault_type`: "normal" (hanging wall drops), "reverse" (hanging wall rises), "strike_slip" (lateral offset)

    **5.24 — Pipe-model hydraulic erosion for hero nodes:**
    In _terrain_erosion.py, implement `pipe_model_erosion(height_grid, iterations=50, dt=0.02, dx=1.0)`:
    - Maintain water_height and flux grids (4-directional: left/right/top/bottom)
    - Each iteration: compute flux `f_new = max(0, f_old + dt*g*dh/dx)`, scale by `K=min(1, d*dx^2/(sum(f)*dt))`
    - Update water height from flux divergence
    - Compute velocity from flux: `vx = (f_left - f_right) / (2*d)`, `vz = (f_top - f_bottom) / (2*d)`
    - Sediment capacity: `C = Kc * sin(slope) * |v| * clamp(d, 0, 1)`
    - Transport: semi-Lagrangian advection of sediment field
    - Deposit/erode based on capacity vs current sediment
    - Only runs on hero nodes (not base tiles) — gated by `is_hero_node` flag

    - Result preserves hero interior gradients while seamlessly matching base at boundary
    - Add `blend_method` parameter to pipeline config: "smoothstep" (default) or "poisson"
    - A/B comparison: compute max seam height difference for both methods, use whichever is smaller
