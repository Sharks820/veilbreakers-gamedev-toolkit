  1. terrain_stochastic_shader.py (F089): Store the full [H,W,2] UV offset array on the
     mask stack via `stack.set("stochastic_uv_offset", offsets, "stochastic_shader")`.
     Export as JSON manifest for Unity consumption. Keep roughness_variation fold but
     also preserve directional data.
  2. terrain_god_ray_hints.py (F088): Store computed hints list on stack via
     `stack.set("god_ray_hints", hints_array, "god_ray_hints")`. Wire
     `export_god_ray_hints_json` into the standard export pipeline (call from
     terrain_unity_export or compose_terrain_node export phase).

  **Blender shader node groups (RGAP subset):**
  3. RGAP-008 Stochastic tiling: In terrain_stochastic_shader.py, add
     `create_stochastic_tiling_group()` — a Blender node group that samples texture at
     3 random UV offsets (from golden ratio hash) and blends by histogram-preserving method.
     This breaks visible tiling patterns.
  4. RGAP-005 Height-blend preview: Add `create_height_blend_group()` node group that
     reads vertex color weights + heightmap texture to produce proper height-based layer
     transitions (not noise Fac).
  5. RGAP-013 Atmospheric fog: Add `create_atmospheric_fog_group()` — a world shader node
     group with exponential distance falloff + height-based density. Parameters: fog_color,
     fog_density, fog_height, fog_falloff.
  6. RGAP-014 Snow SSS: Add `create_snow_sss_group()` — ShaderNodeSubsurfaceScattering
     with Y-dot-normal (world up) projection mask. Snow accumulates on upward-facing surfaces.
     SSS radius ~0.05m, cool blue subsurface color.
  7. RGAP-033 Cloud shadow: Fix terrain_cloud_shadow.py to store cloud shadow mask on stack
     and create a Blender node group that projects animated Perlin noise as shadow cookies.
  8. RGAP-019 Wind animation: Add `create_wind_animation_group()` for vegetation — vertex
     color driven displacement using sine wave + noise modulation. Phase offset from
     object location to prevent synchronized waving.
  9. RGAP-027 Water-terrain intersection: Add `create_water_intersection_group()` — depth-based
     transparency + foam line at shoreline using scene depth comparison.
  10. RGAP-031 Minimap: Add `setup_minimap_camera()` helper that creates an orthographic
      camera looking down, with a dedicated render layer excluding sky/fog, suitable for
      minimap texture baking.
  11. RGAP-028 Decal projection: Add `create_decal_projection_group()` for road/path/scorch
      mark decals projected onto terrain surface.
  12. Waterfall shader: Add `create_waterfall_shader_group()` with flow UV animation
      (scrolling UV offset), foam noise at edges, alpha falloff at base.
  13. River LOD: Add `create_river_lod_materials(lod_levels=3)` producing simplified
      materials at distance (LOD0: full flow+foam+caustics, LOD1: flow+foam, LOD2: flat color).
  </action>
