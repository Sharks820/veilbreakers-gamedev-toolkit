  **Cluster A — Kill split-brain (F270-F276):**
  1. In terrain_materials.py, deprecate the legacy zone API (`ground/slopes/cliffs/water_edges`).
     Add a shim that translates legacy zone names to V2 names (`ground/slope/cliff/special`)
     and logs a deprecation warning. All new code must use V2 names only.
  2. Unify splatmap attribute name to `VB_TerrainSplatmap` everywhere (F271). Delete all
     references to `TerrainSplatmap_<biome>` pattern. The vertex color attribute is created
     BEFORE material assignment (fix F035 ordering bug).
  3. In _mesh_bridge.py, fix material_ids per-face assignment (F275) — ensure `mesh_from_spec`
     actually applies `material_ids` array to face.material_index, not just validates and drops.
  4. Fix cave entrance axis confusion (F276) — standardize on Y=depth, Z=height with clear
     docstring and assert.

  **Cluster B — Real PBR textures (F034-F049, F600-F621):**
  5. In terrain_materials_v2.py, create `build_procedural_pbr_layer(channel: MaterialChannel) -> dict`:
     - For each layer type (ground, slope, cliff, special, wet_rock, snow), build a node sub-graph:
       - Base Color: Musgrave Texture (fBM type) mixed with Voronoi for rock, Wave for sand
       - Roughness: Noise Texture -> ColorRamp (not hardcoded float)
       - Normal: ShaderNodeNormalMap fed by Musgrave-driven bump (not noise bump F037)
       - Uses ShaderNodeTexCoord -> ShaderNodeMapping for proper UV control (fix F041)
     - Wire palette colors as tint multiplied onto procedural base (not replacing it like F036)
     - Call `mesh.update()` after vertex color writes (fix F048)
  6. Fix material double-append (F046) — single append, single slot assignment.
  7. Fix HeightBlend to use actual heightmap samples, not noise Fac (F047).

  **Cluster C — Wire DAG splatmap (F826-F828):**
  8. Add `write_splatmap_vertex_colors(obj, stack)` that reads `splatmap_weights_layer` from
     the DAG mask stack and writes to `VB_TerrainSplatmap` vertex color attribute.
  9. Wire this into the compose_terrain_node flow after mesh creation.

  **Cluster D — Triplanar + displacement (RGAP-001, RGAP-004):**
  10. Add `build_triplanar_projection(node_tree)` that creates a 3-axis sampling group
      (XY, XZ, YZ planes) with blend based on world normal dot product. Use for cliff/steep
      materials where `triplanar: bool = True` on MaterialChannel (fix F038 — make production
      readers exist).
  11. Connect ShaderNodeDisplacement to material output for cliff/rock channels (fix F042).
      Use Midlevel=0.5, Scale from channel config.

  **Cluster E — Macro variation + detail normals (RGAP-002, RGAP-003):**
  12. Add macro variation: low-frequency Musgrave (scale ~200-500m) multiplied into base color
      to break tiling at distance. Prevents "plastic at 30m" (F120/RGAP-002).
  13. Add detail normal blending using Reoriented Normal Mapping (RNM): blend macro normal
      (from terrain heightfield gradient) with detail normal (from procedural texture).
      Implementation: `n = normalize(vec3(macro.xy + detail.xy, macro.z * detail.z))`.
  </action>
