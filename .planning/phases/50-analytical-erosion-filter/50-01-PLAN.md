<interfaces>
From lpmitchell/AdvancedTerrainErosion (MIT+MPL-2.0):
```
Sample(vec2 p, config, seed)
  ├── FractalNoise(p) → base height + analytical derivatives
  ├── fadeTarget = clamp(h / amplitude)
  └── ErosionFilter(p, heightAndSlope, fadeTarget, ...)
       ├── for each octave:
       │    ├── PhacelleNoise(p*freq, normalize(gullySlope), cellScale, ...)
       │    │    └── 4×4 cell grid, cosine/sine stripe pairs oriented along slope
       │    │        blended with bell-curve weights exp(-dist²·2)
       │    ├── gullySlope += sign(sine) * derivatives * strength * gullyWeight
       │    ├── fadedGullies = lerp(fadeTarget, gullies*gullyWeight, combiMask)
       │    ├── heightAndSlope += fadedGullies * strength
       │    ├── combiMask = PowInv(combiMask, detail) * newMask
       │    └── ridgeMapFadeTarget = lerp(ridgeMapFadeTarget, gullies.x, ridgeMapCombiMask)
       └── return (heightDelta, slopeDelta, magnitude), ridgeMap
```

ErosionConfig fields (12):
  Strength, GullyWeight, Detail, Rounding, Onset,
  AssumedSlope, Normalization (~0.4), FadeTarget amplitude factor (~0.6),
  ExitSlopeThreshold (0.0075), CellScale, OctaveCount, Frequency
</interfaces>

  <action>
    Create terrain_erosion_filter.py with:

    1. **phacelle_noise(p, slope_dir, cell_scale, seed)** — vectorized numpy port:
       - 4×4 cell grid around each query point
       - Random pivot per cell via hash function (seed-based)
       - Cosine/sine stripe pairs oriented along slope_dir
       - Bell-curve blending: exp(-dist²·2)
       - Returns (gully_value, sine_derivative, cosine_derivative)

    2. **erosion_filter(height_grid, gradient_x, gradient_z, config, seed)** — main filter:
       - For each octave (config.octave_count):
         - Call phacelle_noise at frequency * position
         - gully_slope += sign(sine) * derivatives * strength * gully_weight (triangle wave trick)
         - faded_gullies = lerp(fade_target, gullies * gully_weight, combi_mask)
         - height_and_slope += faded_gullies * strength
         - combi_mask = pow_inv(combi_mask, detail) * new_mask
         - ridge_map_fade = lerp(ridge_fade, gullies, ridge_combi_mask)
       - Return AnalyticalErosionResult

    3. **apply_analytical_erosion(height_grid, config, seed, cell_size=1.0)** — public API:
       - Compute analytical gradient from height_grid (finite-diff fallback for imported)
       - Compute fade_target from height range
       - Call erosion_filter
       - Return AnalyticalErosionResult

    4. **finite_difference_gradient(height_grid, cell_size)** — gradient fallback (CONFLICT-003):
       - Central differences for interior, forward/backward at edges
       - Returns (gradient_x, gradient_z)

    Use Context7 to look up numpy vectorization best practices for the cell-grid computation.
    All math must be vectorized (no per-pixel Python loops).
