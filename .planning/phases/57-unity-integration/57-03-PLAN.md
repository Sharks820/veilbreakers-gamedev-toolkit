     - Performance: batch modifications per frame, max 4 deformations/frame
     - Reset system: gradual heightmap restoration over time

     - Fog of war: texture mask revealing explored areas
     - Player/NPC/POI icon overlay via UI Canvas on RenderTexture
     - Update frequency: every N frames (not every frame)
