  <name>Task 1: Fix export fundamentals — axis, endianness, resolution, splatmap</name>
  <files>
    Tools/mcp-toolkit/blender_addon/handlers/terrain_unity_export.py,
    Tools/mcp-toolkit/blender_addon/handlers/splatmap_exporter.py,
    Tools/mcp-toolkit/blender_addon/handlers/terrain_chunking.py

  <action>
  1. **F050 Z-up -> Y-up axis swap:** In terrain_unity_export.py, add axis transformation
     before writing heightmap: `height_unity = np.flipud(height_blender)` and swap Y/Z
     coordinates in all vertex/position exports. Add explicit comment "Blender Z-up -> Unity Y-up".

  2. **F051 Endianness:** Force little-endian on all numpy writes:
     `height_u16 = height_u16.astype("<u2")` (little-endian uint16).
     Add assertion: `assert height_u16.dtype.byteorder in ("<", "=")`.

  3. **F052 Resolution validation:** Add `validate_terrain_resolution(width, height)` that
     checks both dimensions are 2^n+1 (33, 65, 129, 257, 513, 1025, 2049, 4097).
     Raise ValueError with helpful message if not. Call before export.

  4. **F058/F059 Splatmap 8+ layers:** In splatmap_exporter.py, remove the hardcoded
     `if len(splatmap_layers) != 4: raise ValueError`. Support up to 16 layers by writing
     multiple RGBA textures: `splatmap_0.raw` (layers 0-3), `splatmap_1.raw` (layers 4-7),
     etc. Update manifest to list all splatmap files.

  5. **F060 Unified export schema:** Consolidate the two incompatible export paths into one.
     Delete the legacy `compose_map` tempdir export pattern. Single manifest format with:
     `heightmap_path`, `splatmap_paths[]`, `vegetation_instances_path`, `mesh_paths[]`,
     `run_id` (UUID), `coordinate_system: "unity_y_up"`, `heightmap_bit_depth: 16`.

  6. **F061 Idempotent export:** Remove the hidden `stack.set("heightmap_raw_u16", ...)`
     from `export_unity_manifest`. Export functions must be read-only on the stack.
     Move U16 conversion to a separate `prepare_heightmap_u16(stack)` called before export.

  7. **F062 Determinism hash:** Compute hash BEFORE any stack mutations, not after.

  8. **F063 Export metadata awareness:** Add `heightmap_resolution`, `splatmap_layer_count`,
     `manifest_path` to the return dict from `handle_export_fbx`/`handle_export_gltf`
     when terrain objects are detected.

  9. **F850-F852 Unity erosion:** Add to export manifest:
     `"erosion_package": {"name": "com.runevision.terrain-erosion", "version": "1.0.0", "source": "git+https://github.com/runevision/LayerProcGen.git"}`.
     Include erosion parameters (octaves, lacunarity, strength) in manifest for C# consumer.

  10. **Tile stitching (F056):** In terrain_chunking.py, add `verify_tile_seams(tiles)` that
      checks height values match at shared borders within epsilon (0.001). Log warning on mismatch.
  </action>
  <verify>
    <automated>cd Tools/mcp-toolkit && python -m pytest tests/test_terrain_unity_export*.py tests/test_splatmap*.py -x -q --tb=short 2>&1 | tail -10</automated>
  </verify>
  <done>
  - Axis swap Z-up -> Y-up applied on all exports
  - All heightmap writes are little-endian uint16
  - Resolution validation rejects non-2^n+1 dimensions
  - Splatmap supports up to 16 layers via multiple files
  - Single unified export manifest format
  - export_unity_manifest is read-only on stack
  - Hash computed before mutations
  - Tile seam verification exists
  </done>
