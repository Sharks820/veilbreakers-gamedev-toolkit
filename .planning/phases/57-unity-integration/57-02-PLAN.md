  **Cluster B — C# consumers (F188-F203):**
  1. **F188 Endianness:** In scene_templates.py C# heightmap reader, use explicit
     `BitConverter.ToUInt16(rawBytes, i)` which handles endianness, or
     `BinaryReader` with explicit little-endian. Remove manual bit shifting.

  2. **F189 File size validation:** Add `if (rawBytes.Length != resolution * resolution * 2)
     throw new ArgumentException($"Expected {resolution*resolution*2} bytes, got {rawBytes.Length}");`

  3. **F190 Parameterized asset path:** Change `"Assets/Terrain/Generated/VB_TerrainData.asset"`
     to accept `string outputPath` parameter with that as default. Generate unique paths
     when called multiple times.

  4. **F191 JSON serialization:** Replace hand-built JSON string concatenation with
     `JsonUtility.ToJson()` or a proper `StringBuilder` that escapes values. Fix Windows
     path backslash escaping.

  5. **F192 Missing heightmap:** Change from `Debug.LogWarning` + continue to
     `Debug.LogError` + `return` early. Do not silently create flat terrain.

  6. **F193-F194 Manifest consumption:** Add `manifest_path` parameter to
     `_handle_scene_setup_terrain`. Read manifest JSON to get `terrain_size`,
     `world_origin_x_m`/`world_origin_z_m`, `coordinate_system`, `heightmap_bit_depth`.
     Use these instead of hardcoded `(1000, 600, 1000)`.

  7. **F195 Alphamap normalization:** Add proper weight normalization in C# reader:
     clamp negative to 0, clamp NaN to 0, normalize row sum to 1.0. Log warning if
     correction exceeds 0.1 threshold.

  8. **F196 Tiled neighbor wiring:** Add assertion that `flip_vertical` matches export convention.

  9. **F199 NumPy channel reader:** Generate a C# `NpyReader` utility class that reads
     `.npy` format (NumPy file header + raw data). Support float32, float64, uint16, int32.
     This enables Unity to consume the 10+ DAG channels.

  10. **F200 TreePrototype + DetailPrototype:** Add `SetupTerrainTrees(TerrainData, TreeInstance[])` and
      `SetupTerrainDetails(TerrainData, DetailPrototype[])` in the C# template. Read
      `tree_instance_points` and `detail_density` from export manifest.

  11. **F201 Navmesh consumer:** Add `ImportTerrainNavMesh(string jsonPath)` that reads
      `navmesh_export.json` and creates a Unity NavMeshSurface or NavMeshModifierVolume.

  12. **F202 Position parameter:** Add `Vector3 terrainPosition` parameter to setup_terrain,
      read `world_origin_x_m` / `world_origin_z_m` from manifest.

  13. **F203 Splatmap format:** Detect file extension (.png vs .raw) and use appropriate
      reader. Prefer .raw (matches Unity expectation). Log error if PNG detected.

      - `unity_qa.play_session` -> correct action
      - Delete or fix `generate_pipeline_orchestrator_script` theater (F370)

  15. Fix world_templates.py terrain-related issues (F374-F381):
