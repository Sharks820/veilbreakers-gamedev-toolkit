  <action>
  **Geometric quality tests (test_geometric_quality.py):**
  1. Manifold mesh test: Generate terrain mesh via pipeline, verify:
     - Zero non-manifold edges (every edge has exactly 2 faces)
     - Zero non-manifold vertices
     - Consistent face winding (all normals point outward)
  2. Normal quality test: Verify face normals are non-zero, no NaN normals,
     average normal dot product with (0,0,1) > 0 (terrain faces mostly up).
  3. Degenerate face test: Verify zero degenerate faces (area < epsilon),
     zero zero-area triangles, no duplicate vertices at same position.
  4. UV quality test: If UVs exist, verify no overlapping UV islands,
     texel density variance < 4x between min and max.
  5. Material assignment test: Every face has a valid material index,
     no faces reference out-of-bounds material slots.

  **Statistical terrain tests (test_statistical_terrain.py):**
  6. Height distribution: Generate 513x513 terrain, verify:
     - Height values span at least 50% of configured range
     - Distribution is not uniform (natural terrain is not flat noise)
     - No height values are NaN or Inf
  7. Slope analysis: Compute slope from height gradient, verify:
     - Mean slope is in realistic range (5-45 degrees for mountainous)
     - Max slope < 89 degrees (no vertical walls except cliffs)
     - Slope distribution has long tail (few steep, many gentle)
  8. Fractal dimension: Compute box-counting fractal dimension, verify:
     - D is in range [2.0, 2.5] (natural terrain is ~2.1-2.3)
     - D > 2.0 (not flat plane)
  9. Spectral power: FFT of heightmap, verify:
     - Power spectrum follows approximate 1/f^beta (beta in [1.5, 3.0])
     - No dominant single frequency (not periodic tiling)
  10. Autocorrelation: Verify spatial correlation decreases with distance
      (terrain is not random noise but has spatial structure).

  **Physical plausibility tests (test_physical_plausibility.py):**
  11. River flows downhill: For each river path, verify monotonically
      decreasing height (with tolerance for numerical noise < 0.1m).
  12. Drainage acyclic: Build flow accumulation graph from D8 flow directions,
      verify the graph is a DAG (no cycles). Use topological sort.
  13. Erosion V-shaped: At river cross-sections, verify valley profile is
      V-shaped (not U-shaped or flat). Width increases with depth.
  14. Cliff angle: Cliff faces have slope > 60 degrees.
  15. Lake level: All points within a lake polygon have height within
      epsilon of the lake surface level (flat water).
  16. Sediment conservation: Total erosion volume approximately equals total
      deposition volume (mass conservation within 20% tolerance).

  **Cross-feature + LOD + export tests (test_cross_feature_lod_export.py):**
  17. Feature coexistence: Generate terrain with cliffs + rivers + caves enabled.
      Verify all three produce non-empty geometry. No feature silently suppresses another.
  18. LOD consistency: LOD0 and LOD1 meshes have same bounding box (within 1%).
      LOD1 has fewer triangles than LOD0. LOD2 has fewer than LOD1.
  19. Export roundtrip: Export heightmap to Unity format, read back, verify
      height values match within uint16 quantization tolerance.
  20. Splatmap consistency: Splatmap weights sum to 1.0 per vertex (within 0.01).
      No negative weights. No NaN weights.
  21. Material coverage: Every terrain biome zone has at least one material
      assigned. No "default gray" materials on the final mesh.

  All tests use real numpy arrays and pipeline functions. Zero MagicMock.
  Each test must FAIL if the tested function returns `None` / empty / `pass`.
  </action>
