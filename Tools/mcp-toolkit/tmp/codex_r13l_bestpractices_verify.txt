AAA web comparison (current docs / practice)
- Unreal Water System (UE 5.6) describes a spline-based workflow for rivers, lakes, and oceans with unified shading/meshing and gameplay interactions. The plan covers rivers/lakes/ocean meshes, but not a unified spline-native water authoring contract with transition materials / interactions.
- Unreal Landscape Edit Layers (UE 5.6) explicitly supports non-destructive edit layers and layers reserved for splines. The plan has roads, rivers, and A* pathing, but not a reserved spline-layer workflow for non-destructive terrain deformation.
- Unreal Runtime Virtual Texturing (UE 5.6) says RVT works especially well for landscapes and improves spline/decal-type effects. The plan still lacks an explicit RVT / virtual texturing phase.
- Unreal World Partition (UE 5.6) is the current large-world cell-streaming baseline. The plan has seam correctness and some streaming-adjacent work, but no explicit world-partition / HLOD / data-layer runtime strategy.
- Unreal PCG Overview (UE 5.6) shows current AAA tooling expects graph-based biome/world generation that can attach to World Partition data layers and HLOD layers. The plan has procedural passes and scatter, but not an explicit PCG/data-layer orchestration model.
- Unity Terrain neighbor workflows (Create Neighbor Terrains / Terrain.SetNeighbors) emphasize seam-safe neighboring tiles and LOD matching. The plan DOES cover this area well through Phase 5 seam guards, edge matching, and cross-tile validation.
- Unity Terrain Layers support reusable terrain layers, mask maps, and height-based blending. The plan partially covers this with shader/material upgrades, but it does not explicitly call out height-based blend + mask-map authoring rules.

Additional AAA techniques not clearly covered by the plan
- Non-destructive spline-reserved terrain layers for roads/rivers/shoreline terraforming.
- Explicit runtime virtual texturing / terrain virtual texturing.
